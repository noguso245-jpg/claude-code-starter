## セットアップ（3ステップ・5分）

```bash
# 1. このリポジトリをクローン
git clone https://github.com/noguso245-jpg/claude-code-starter

# 2. プロジェクトの.claude/フォルダにコピー
cp claude-code-starter/templates/CLAUDE.md your-project/.claude/CLAUDE.md

# 3. Claude Codeを起動
claude
```

これだけです。
